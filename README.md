# Downloads

Hier staan de installatiebestanden en updates van het programma voor Windows.

## Installeren

1. Ga naar [Releases](../../releases/latest).
2. Download het bestand dat eindigt op `_x64-setup.exe`.
3. Dubbelklik het bestand en volg de installatie.

Windows kan bij de eerste keer waarschuwen dat de maker onbekend is. Klik dan op
"Meer informatie" en daarna op "Toch uitvoeren".

Werkt op Windows 10 en 11. Je hoeft verder niets te installeren.

## Updates

Het programma kijkt bij elke start of er een nieuwe versie is en installeert die na
een klik. Je gegevens blijven daarbij gewoon staan.
